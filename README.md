# 📘 Common Programming Concepts in Rust

Este repositório contém exemplos práticos, exercícios e projetos focados nos **conceitos fundamentais de programação usando a linguagem Rust**.

A ideia é explorar, com clareza e robustez, princípios como:

- Variáveis e mutabilidade (constantes)
- Bloco e Sombreamento
- Tipos Escalares
- Tipos Compostos
- Funções
- Controle de Fluxo
- Cálculo do Fatorial
- Números Primos
- Argumentos na Linha de Comando
